# Assignment 2 – Set C – Q2: Instructor-Provided Relationship

## Lab-book task
Document the required approach for the second blank Set C exercise.

## Solution
The workbook does not provide the actual values in the supplied text; it instructs the instructor to fill the blanks. Do not substitute an unrelated schema. Once the relationship is supplied, map it using the workbook rules: one-to-many → foreign key on the many side; many-to-many → new junction relation; one-to-one → unique foreign key on the participating side.
