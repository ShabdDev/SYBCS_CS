# S.Y.B.Sc. Computer Science – Complete Lab Book Solutions

This folder contains set-wise solutions for the supplied S.Y.B.Sc. (Computer Science) Data Structures I and Database Management Systems I workbook.

## Organization
- `assignment1_...` through `assignment6_...`
- `SetA`, `SetB`, `SetC` are separated by filename.
- Data Structures solutions are C programs.
- Database Management Systems solutions use PostgreSQL SQL.
- Where the workbook leaves blanks or asks the instructor to fill values, the solution preserves that dependency and marks sample substitutions clearly.

## Compile C programs

```text
gcc filename.c -o program
./program
```

For a header-library exercise, keep the `.h` file in the same directory as the `.c` file.

## PostgreSQL

Run SQL in `psql`. Commands such as `\d table_name` are PostgreSQL `psql` meta-commands, not SQL statements.

## Source
The source workbook is the uploaded S.Y.B.Sc. (Computer Science) Semester III workbook for Data Structures I and Database Management Systems I, Course Code CS-203-MJ-P.
